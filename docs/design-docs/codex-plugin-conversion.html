Plugin 隔离

Project Codex Home

每个项目使用 ~/.ad/codex-homes/<project-id>，Plugin config、marketplace 和 cache 都只存在于这个 runtime。

自动继承

Base + Overlay

AD 只读默认 ~/.codex/config.toml，结构化合成“用户默认 + 项目 Plugin overlay”。用户无需手工维护两份配置。

作用边界

仅 AD scoped launch

AD 启动时注入项目 CODEX_HOME。普通终端、IDE 或默认 Codex 启动仍使用 ~/.codex，Project Plugin 不生效。

运行时隔离架构

默认 home 的配置与 Plugin store 只读；用户登录态是共享引用。Project runtime 是派生 Codex installation，Preview、Apply、Process 与 Launch 都绑定同一个 installation id。

配置如何合并

输入 A 所选默认 Codex installation/config.toml [只读] 输入 B Project Plugin overlay [AD-owned] 输出 Project Codex Home/config.toml [原子生成] 运行时 precedence： 项目 .codex/config.toml > Project Home/config.toml > system defaults

认证与 Profile：用户身份共享，项目差异分层

ChatGPT 登录态必须复用文件认证由 Project Home/auth.json 受控链接到 Base auth。AD 只管理路径元数据，不打开、复制、diff 或备份 token；Codex refresh 写回共享 auth 是预期行为。
Keychain-only 必须提前分流Codex Keyring key 按 canonical CODEX_HOME 隔离，文件链接无法复用。Preview 必须阻塞并提供共享 Home/Profile 或 file store 选择，不能退回每项目重新登录。

API Key、模型和环境变量等项目差异属于 AD Profile。本轮 Plugin 转换只消费可选 profile_id；Profile 自己管理敏感值与启动注入。

Plugin 自动安装：从 Preview 到 Codex 可发现

AD 不隐藏执行 Codex 命令，而是直接生成官方安装器相同的持久化结果。网络解析、确定性写盘和启动被拆成三个边界；只有 Apply 修改有效 Project Home。

阶段具体动作失败语义
Inventory读取 Project settings、enabledPlugins、known marketplace 与已安装 source；disabled 立即 unchanged。输入无法解析则逐项 conflict，不访问网络。
Resolve + TransformGit/local source 进入 AD 临时 stage；校验 catalog、ref、name/version/path。原生 Codex package 原样保留，可映射 Claude package 生成最小 .codex-plugin/plugin.json。未知组件进入 partial/unsupported；stage 不进入有效 Home。
Preview展示 route、revision、version、components、tree digest、所有 targets、残留项与冲突，保存 backend-owned MutationPlan。用户未确认不写盘；source/target drift 使 plan 失效。
Apply加项目锁并复核 digest；备份后写 auth link、marketplace snapshot、plugins/cache/<marketplace>/<plugin>/<version>，最后写 config。逆序补偿；目录未齐全前绝不出现新 enabled = true。
Verify + Launch重读 config/manifest/digest，记录 receipt；Launch 仅注入 CODEX_HOME、cwd、可选 profile。过期回到 Preview，不在启动路径偷偷刷新。

关键验收

隔离证明

默认配置与 Plugin 不变

Project Apply 前后，默认 config、marketplace 与 Plugin cache digest 完全一致；共享 auth refresh 单独排除。

真实隔离

同项目，不同启动结果

AD scoped launch 可见 Project Plugin；普通 Codex 启动不可见。

自动继承

Base 更新可刷新

默认用户配置变化后自动产生可预览 refresh，无需手工复制。

共享认证

项目无需重复登录

文件认证复用用户登录；AD 仅验证 auth link。Keychain-only 不假成功，项目 API Key 由 Profile 覆盖。
