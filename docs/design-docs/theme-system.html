AD Design System · Theme

Catppuccin Mocha，作为系统而非皮肤

默认深色使用 Mocha，亮色兼容使用 Latte。所有界面先选择语义角色，再由主题映射颜色；主窗口、Settings、CodeMirror 与首帧原生背景共享同一视觉契约。

设计原则

Catppuccin 提供色彩语言，AD 的语义层负责产品一致性。强调色用于意义，中性色负责空间。

01 · Semantic

语义优先

组件使用 canvas、surface、text、action、status，不依赖 Mocha 色名。

02 · Hierarchy

中性色建层级

Base、Mantle、Crust、Surface 建立窗口、pane 与控件深度。

03 · Parity

双主题同构

Mocha 是默认；Latte 保留已发布 light mode，但语义角色完全一致。

04 · Access

可读性优先

关键文本不降到 Overlay；状态同时依靠文案、图标、边框或形状。

Token 架构

Palette 只在 globals.css 出现一次。新组件不得跳过 AD semantic token 直接引用 palette 或 hex；旧 clay/rust/olive/oat/slate2 aliases 已删除。

启动 Loading 生命周期

首帧在 React bundle 之前出现，真实初始化完成后才揭幕；它是启动状态边界，不是虚假进度条。

Visual contract

Logo + “Be Water, My Friend”

只显示现有 AD logo 和原句。探照灯每 10ms 前进一步，30 步完成一轮 300ms 扫描；高光只裁剪在字形内，并由启动 helper 驱动以保证 WKWebView 逐帧重绘且不与屏幕刷新率混叠。Mocha/Latte 非高亮对比度均不低于 4.5:1。reduced-motion 停止 logo 呼吸和高光循环。

Ready contract

真实 settlement + 12s deadline

Agents 与 Projects 并行，Profiles 等 Agent attempt。全部 settle 后揭幕；rejection 或整体超时 fail-open，晚到的幂等 read 仍可渐进更新 store。

Access boundary

遮罩退出前保持 root 隔离

Splash 存在和 260ms 交叉淡入淡出期间，React root 保持 inert + aria-hidden。静态层只暴露一个 localized polite/atomic status，移除遮罩后恢复且不抢焦点。

Window scope

主窗口协调，Settings 只复用首帧

主窗口等待三组 store 初始化；Settings route 不触发这些读取，只在自身首次 paint 后执行相同揭幕协议。

未来功能必须遵循

应当

先选择语义角色；缺少角色时更新设计文档与基础层；双主题、键盘 focus、状态非颜色线索一起验收。

禁止

新增 raw hex、bg-black/*、framework emerald/red、透明白灰或新的 --ds-* 产品样式。用户 Profile 数据色是明确例外。

自动守卫

themeContract.test.ts 固定 palette、首帧、label contrast 与 focus；themeSurfaces.test.tsx 递归拒绝产品 TSX 原始色并校验兼容 token 完整性。

运行时边界

theme.ts 同步双窗口根节点；Rust 固定 native paint；JsonEditor 只切换官方 Catppuccin extension。
