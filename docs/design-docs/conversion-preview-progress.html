产品结果

真实反馈

阶段更新来自后端真实调用边界；当前处理项使用 Plugin logical id，计数只在总数已知时出现。

不制造精确假象

目录大小差异很大，current/total 不等于耗时比例，因此不绘制百分比进度条，也不预测剩余时间。

后台计算

Tauri command 使用 async 响应，并把同步文件扫描和目录摘要放入专用 blocking worker；IPC 与 WebView 可在 Preview 完成前持续接收事件和重绘。

接口与安全边界

事件字段

  • phase：稳定语义枚举
  • current / total：可选计数
  • item：已公开的 logical id

明确不发送

  • 认证、token、配置内容
  • backend-owned mutation content
  • 目录内文件名或扫描明细
  • 估算百分比与剩余时间

自动化门禁
