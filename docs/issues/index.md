## 严重程度定义

- **Critical**：丢用户数据 / 损坏 settings / 崩溃
- **High**：核心功能不能用
- **Medium**：影响体验，但有 workaround
- **Low**：边角问题、视觉 glitch

## 状态定义

- **Open**：已确认，待修复
- **In Progress**：有 ExecPlan / 正在修
- **Fixed**：已修，待验证
- **Closed**：已修复 + 验证通过
- **Won't Fix**：已确认不修（注明原因）
