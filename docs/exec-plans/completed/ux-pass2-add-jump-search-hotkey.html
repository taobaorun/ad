关键决策

D1 · PLUGIN
全局快捷键 = tauri-plugin-global-shortcut
Tauri 2 官方插件，API 稳定，接受字符串 binding（"Alt+Cmd+KeyA"）。备选 rdev 是 raw 输入劫持，权限要求与误伤面更大，否决。
D2 · KEY
默认绑定 ⌥⌘A
⌃⌥⌘A 三键修饰物理上费手；⌘⇧Space 与系统输入法切换/Spotlight 衍生有冲突风险；⌥⌘A macOS 系统与常见 app（VSCode/Chrome/Slack/Notion）均未占用，A 又对应 "AD"，语义直观。
D3 · PERSIST
偏好沿用 useUiSettings localStorage，不开 ~/.ad/state/
是逐设备 UI 偏好，已有 localStorage + 跨窗口同步基建。后端不直接读 webview localStorage —— 前端在 boot 时调一次 IPC 把当前 prefs 同步给后端，注册由后端落实。
D4 · UI
录键 UI 不引入第三方库
最简实现：一个 "Press keys…" 按钮 + 监听 keydown + Esc 取消。组合键格式化逻辑约 30 行。引入 react-hotkeys-hook 类库属于过度工程。
D5 · BEHAVIOR
同一快捷键 = toggle visibility
按 ⌥⌘A 时：窗口已可见且聚焦 → hide；否则 show + focus。与 Raycast / Alfred 行为一致，避免"按了第二下没反应"。
D6 · ACTIVE
批量加 project 时定位"第一个成功的"
多选 N 个 project 都"新"，但 sidebar 排序最上的那个心理预期最强。如果用户希望"全选模式下不打断现选中"，请明确，否则按本方案。
