01

目的 / 用户价值

变更后用户能做到：

  • 在任何项目目录起 claude，AD 不影响别的项目，也不污染 ~/.claude/settings.json
  • 同一个 profile 可应用到多个项目，互不串扰
  • 项目内修改正确落到 .claude/settings.json（团队共享）和 .claude/settings.local.json（个人）
  • env 层（ANTHROPIC_API_KEY 等）以"复制 export 片段"形式呈现
  • 项目里已有同名 settings 时做 deep merge；冲突字段让用户逐个选择
  • 添加项目零摩擦：auto-detect from CC history (默认) + 用户自定义扫描根 / drag-drop / tab-complete paste
  • AD 数据完全独立于 CC：所有 AD 状态在 ~/.ad/
可观察验收 打开 AD → 顶部"Detected 12 projects" → 搜索过滤或加 ~/dev/ 到 scan roots → 多选 [Add] → 选 profile → Apply → Y/.claude/settings.local.json 被原子写入；冲突时看到冲突表选择保留 / 替换；~/.ad/ 里能看到 backup 和 history。

06

Project 管理协议

AD 的 project 是用户标记过的目录路径列表，AD 内部状态，CC 不读。

数据模型

// ~/.ad/state/projects.json
{
  "path": string,            // canonical 主键
  "display_name": string,    // 默认 basename
  "added_at": ISO8601,
  "current_profile_id": string?,
  "last_applied": { ... } | null
}

// ~/.ad/state/scan_roots.json (D12)
[
  { "path": "~/.claude/projects",
    "kind": "cc_projects_meta",
    "builtin": true },
  { "path": "~/dev",
    "kind": "generic" }
]

生命周期协议

添加 · canonicalize → 去重 → write_atomic。display_name 默认 basename，可双击 rename。

删除 · 移除 + 确认；不动项目里 .claude/、不动 history、不动 backups。

rename · 仅改 display_name，path 不可变。

路径不存在 · 灰态 + "Remove?"。

不监听 fs · 不当 fsnotify watcher。

扫描根可扩展 · 用户能加 generic root（如 ~/dev/），AD 一层深扫含 .git/.claude 的子目录。

10

关键决策

12 条设计选择。绿框是新增（D8 / D9 / D10 / D11 / D12）。

D1 · 范围边界

只支持 shared / local / env 三层

enterprise managed 和 CLI flag 层不做。

D2 · env 层处理

env 不写文件，只展示 + 复制

写文件方案太多，AD 不替用户做选择。

D3 · 老 schema 迁移目标

老 settings 字段 → layers.local

local 不进 git，最安全的默认。

D4 · projects.json 归属

AD 内部状态，CC 不读

避免和 CC 配置体系耦合。

D5 · apply 触发方式

显式动作，不后台同步

自动同步会意外覆盖项目本地修改。

D6 · legacy 路径处置

保留全局覆盖，藏到 Advanced

老用户已习惯，删掉是 breaking。

D7 · git 状态处理

写 shared 前看 git，警告但不阻塞

shared 是团队级动作，必须知情同意。

D8 · A3 修订 · merge 语义

apply 不覆盖，是 merge + 冲突显式

目标不存在直接写
无重叠 / 重叠值同自动 merge
重叠值不同冲突表 (Frame 3)
D9 · Project 身份

canonical 绝对路径 = 主键

不追踪 mv，不监听 fs。

D10 · Backup 路径统一

~/.ad/backups/<ts>-<slug>-<layer>.json

AD history 一处统一读；删 project 不连带删 backup。

D11 · AD 与 CC 数据完全分离

AD 整体迁到 ~/.ad/，~/.claude/ 只放 CC

语义清晰，未来卸载干净。

D12 · Project 添加 + 可扩展 scan roots

三机制 (auto-detect + drag + tab-paste) + 用户可加 generic scan roots

主路径 scan roots 默认含 ~/.claude/projects（builtin），用户可加 ~/dev/ 等 generic root。folder picker 入口移除。

覆盖 95%（CC 历史）+ 自定义扫描根（剩 5%），都比 folder picker 快。
