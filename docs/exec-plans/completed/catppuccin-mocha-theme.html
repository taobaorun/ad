保留亮色能力

Mocha 是默认；Latte 作为同构亮色映射。不会因主题优化删除当前 light/dark preference。

不重做布局

只统一颜色、状态、边界与 focus；侧边栏、信息架构、图标、Agent 工作流保持不变。

关键决策

选择统一语义层，而不是把现有硬编码逐个换成另一批硬编码。

D1

三层 token 架构

官方 palette → AD semantic roles → Tailwind、兼容 bridge 与组件。未来功能不直接消费 palette 色名。

D2

Mocha + Latte 同构

满足 Mocha 方向，同时避免把已发布亮色能力替换为旧 Zinc/Indigo 旁路。

D3

Sapphire 为主强调

按用户反馈放弃 AI 感明显的 Mauve；Sapphire/Blue/Sky 构成更冷静的专业工具色系。

D4

官方 CodeMirror theme

避免手工维护 syntax 色表；保留现有 WKWebView base layout CSS。

D5

精准迁移，不做邻近重构

组件 ownership、layout、state 与业务行为不变；只清理主题相关 raw color 与状态表达。
