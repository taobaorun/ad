两种明确模式

继承开启 · 默认

结构化合成 Base model、MCP、agents、features、marketplaces 与 enabled plugins；镜像已启用 Base Plugin。

继承关闭 · 隔离

从空 TOML 开始，只加入 AD 必需字段与 Project Plugin overlay；不携带 Base profile。

安全收敛原则

来源可证明

不再从合并后的 config 反推 Project overlay；manifest 是分层来源真源。

删除有双重保护

只有 owner=base 且当前 digest 匹配才删除；Project 与未知旧缓存保留。

Preview 无副作用

策略和 profile 与 config 一起在 Apply 事务内提交，失败由现有 backup/rollback 恢复。

验收底线

  • on → off → on 可重复、幂等，Project Plugin 始终保留。
  • off 模式忽略 Base config drift，但 generated config / manifest drift 仍阻止启动。
  • Preview 与真正 Apply 都显示应用内 loading，不退化成仅系统忙碌光标。
  • 旧项目、旧 runtime 默认继承，无需人工迁移。
  • pnpm typecheck、前后端全量测试与 pnpm tauri build 通过。

不在本次范围：独立 shareBaseAuth 开关、Project Profile 管理、Launch 自动刷新、猜测性删除旧缓存。
