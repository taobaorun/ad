01

目标与不可妥协边界

“管理全部”不是所有按钮都能点，而是所有影响项目的资源都可见、来源可解释、动作状态真实、写入可恢复。

用户完成态

用户打开项目即可知道最终生效的配置与资源；能在项目边界内完成真实支持的安装、启停、同步和移除；转化结果对每项给出唯一状态；任何失败、外部步骤或残留都不会被包装成成功。

隔离项目 A 的操作不改变项目 B 或未确认的用户层。
可解释继承、覆盖、winner、ownership 与 coverage 由后端判定。
可恢复所有写入都经过 context-bound plan、回执与 digest-protected rollback。
02

统一数据与写入链

UI 不再猜 Agent-specific JSON；Conversion 也不再拥有另一套资源语义。所有入口通过同一 workspace contract。

实线是 inspect/inventory；clay 虚线是需要用户确认的计划与写入。Raw snapshot 和 mutation content 不进入 UI 决策层。

03

决定计划成败的技术取舍

这些不是实现细节偏好，而是防止产品再次出现双轨、越界写入和“假完成”的边界。

WORKSPACE IDENTITY

Context 由后端签发

Workspace key 包含 canonical project、base/effective installation 与 runtime revision；前端不再拼装安全身份。

ISOLATION

项目页只写项目落点

Inherited user resource 默认 inspect-only；不存在项目 override 时明确 external/unsupported，不回退到全局写入。

REVISION

Skill 项目采用固定 revision

受控 staging 生成规范 tree manifest 并原子发布 immutable artifact；项目 update 显式 retarget 当前项目。

LIFECYCLE

动作状态逐项计算

同一 Agent 内不同来源、scope、ownership 可以拥有不同的 install/update/remove 能力与下一步。

AUTHORIZATION

Apply 绑定 workspace 与 risk set

Backend claim 重验 public-plan revision、workspace key、source/target digest、single-use acknowledgement 与风险指纹。

RESULT

Receipt 与 domain report 分层

Receipt只记录attempted mutation；Workspace/Conversion report保存external、conflict、unsupported与residual。

MIGRATION

Legacy 只读盘点后再迁移

新状态与 receipt 持久化成功后才归档旧 project state；重复运行幂等，外部目标永不清理。

SOURCE SECURITY

Source 输入默认不可信

固定 login-shell probe 只解析可信 Git 与最小认证环境；实际调用使用结构化 argv，并受 network/time/disk/tree budgets 约束。

CONFINEMENT

Ancestor race 不可越界

Project、Runtime 与 AD-state root 使用 held directory descriptor 和 fd-relative no-follow 操作；字符串或验证后重查都不是充分边界。

DURABILITY

Crash 与多实例进入正常模型

Physical target与startup recovery使用跨进程锁；journal文件和父目录完成durability sync后才推进状态。

SENSITIVE DATA

敏感 Settings 默认不跨 scope

Credential、token、MCP env与疑似敏感值默认遮罩并只作read-only dependency；receipt和journal不保存正文。

COMPATIBILITY

完整性绑定 Agent 版本

Unknown future version、schema、layer或location会把coverage降为partial/failed，不能宣称“全部资源”。

HUMAN ONLY

Rollback 也需要新计划

本轮没有公共 CLI/MCP；危险权限、activation 与 rollback 使用 fresh inverse preview 和显式第一方确认。

05

实施单元

展开查看每个单元的结果与主要验证。完整文件级映射在同目录 Markdown 与统一实施计划中。

U1Workspace identity, resource keys & contracts
结果：Backend-signed workspace、effective/declaration identity、sealed Agent/AD-state targets、versioned discovery、typed inventory与receipt/report分层。
验证：Rust/TS fixtures、unknown future Agent schema、stale/replay/risk mismatch与partial coverage。
U10Execution confinement, locking & crash recovery
结果：Held root descriptors、fd-relative writes、cross-process locks、synced journal、legacy receipt、ownership与rollback inverse plan。
验证：Active ancestor race、unsafe AD root、two-process contention、sync/crash boundary、tampered ownership与rollback activation。
U2Secure immutable Skill acquisition and migration discovery
结果：GUI-compatible trusted Git launch、network/time/disk budgets、AD-state staging、tree manifest、immutable artifact与只读legacy分类。
验证：Hostile source输入零越界；更新A不改变B/global；timeout、artifact collision、special file与legacy slug conflict fail closed。
U3Effective inventory and lifecycle planners
结果：Claude/Codex provenance、version-bound coverage、ownership、health、runtime与install/toggle/update/remove策略。
验证：Inherited remove不产生user delete；unknown version或unprepared/future-manifest runtime fail closed；同坐标不同package bytes进入conflict。
U8Effective Settings and project-layer editing
结果：字段级provenance、winner、sensitive masking、editable target与semantic unknown-field preservation。
验证：User/shared/local precedence、base/overlay、dirty draft guard、no cross-scope secret copy、no-change plan。
U4Unified Project Agent Workspace UI
结果：一个项目入口完成真实生命周期，风险信息分层，前端只消费backend descriptor/actions。
验证：五种empty/error状态、dirty/stale context、keyboard/focus/live status、detached apply与report/history。
U5Backend Conversion reconciliation
结果：后端转换有效项目环境，复用resource planners，生成独立ConversionReport。
验证：Inherited source、project-only target、replay、conflict、compensated/partial与domain dependency单向性。
U9Conversion workspace UI integration
结果：Resolution提交后后端re-preview，risk fingerprint、safe subset、progress、report/receipt与rollback共用workspace identity。
验证：Required residual阻止full Apply；safe subset必为partial；generic confirm不可绕过；detached结果归档原workspace。
U6Legacy state retirement
结果：ProjectSkills、project allowlist/blocklist、legacy Plugin toggle 与 direct-write IPC 退出。
验证：旧状态兼容读取、显式 preview、迁移 marker、失败不清理 external/legacy data。
U7Completion evidence and documentation
结果：README/spec/design 使用统一产品身份与 evidence level。
验证：全量前后端门禁、Tauri production build、安装 app 的 A/B 隔离与恢复 workflow。
