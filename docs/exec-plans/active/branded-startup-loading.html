关键决策

D1

复用 pre-React splash

比 React-only loader 更早，比独立 Tauri splash window 更简单，也能继续满足 native / HTML / React 首帧主题合同。

D2

settlement 驱动退出

真实数据加载决定何时揭幕；失败同样 settle，避免永久 loading。当前无 retry 产品流，不在本任务扩 scope。

D3

不延迟窗口 show

保留 Rust page-load reveal；ready 只移除 overlay、不抢焦点，不重新引入现有 bundle 计划已经否决的 deferred-show。

D4

无障碍是效果的一部分

探照灯不承担可读性；reduced-motion 关闭循环动画，Mocha / Latte 都保留完整静态文案。

预计 7 步

0 · 冷启动前置门禁

拆分 pre-WebView migration 与 WebView 后初始化；若前者占主导，停止扩 scope。

1 · 红灯合同

先固定启动顺序、并发、失败 settlement、logo / spotlight / reduced-motion。

2 · Startup coordinator

Agent 尝试优先；Profiles / Projects 随后并行；返回结构化失败。

3 · Bootstrap 集成

main 初始化一次，App 移除重复加载，Agent 切换仍刷新 Profiles。

4 · 品牌 Loading

真实 logo、i18n slogan、探照灯、主题与 reduced-motion fallback。

5 · Production 冷启动

完整测试、Vite/Tauri build、Mocha/Latte/失败路径实机检查。

6 · LFG 交付

as-built 文档、简化、review 修复、browser QA、commit、PR、CI。
